# HightTeQ

Plateforme e-commerce de produits technologiques et services informatiques
(Madagascar). Le panier ne déclenche pas un paiement en ligne : il génère
un message pré-rempli envoyé sur WhatsApp Business, où un conseiller
prend le relais humainement.

## Stack
- Backend : Django + Django REST Framework + PostgreSQL (cloud)
- Frontend : Next.js + Tailwind CSS

## Structure
- `backend/` — API Django
- `frontend/` — application Next.js
- `documents/` — cahier des charges et documentation
